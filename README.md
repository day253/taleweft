# TaleWeft · 织声

以故事为线，将人声、音乐与音效织成一部剧。

TaleWeft 面向有声剧、广播剧和有声小说制作，计划通过可切换的 AI 音频模型，将剧本、角色表演、环境声与配乐组织成完整的声音作品。

## 项目状态

项目初始化阶段。当前仓库包含项目介绍，尚未实现业务功能或接通音频生成服务。

## 支持的内容类型

以下三种类型均纳入产品范围，可按作品选择制作方式：

- **有声剧**：以多角色表演和场景叙事为核心，组织对白、旁白、配乐与音效。
- **广播剧**：面向完整的声音戏剧制作，强调剧本改编、角色调度、场景衔接和声音设计。
- **有声小说**：面向长篇叙事和章节制作，支持单人演播或多角色演播，关注旁白连贯性及跨章节的声音一致性。

三种类型共享作品、角色、场景、版本和素材管理能力，不将内容类型与某个模型绑定。

## 制作方向

- 剧本与分场：管理作品、分集、场景、对白和旁白。
- 角色与声音：记录角色设定、音色参考和表演指令。
- 音频创作：将对白、情绪、环境声和配乐编排为场景提示词，调用音频创作模型。
- 试听与返修：比较生成版本，标记问题并重做指定场景。
- 成品整理：组织分集音频、字幕和制作素材，支持后续导出。

## 技术方向

- **工作流编排**：Mastra / TypeScript。
- **音频模型接入**：通过统一的模型适配接口接入不同提供商，按项目或场景选择适合的模型；火山引擎 Seed Audio 1.0 是可选接入之一。
- **制作单元**：以场景为单位组织生成与返修，再组成完整分集。

## 模型接入原则

- 将剧本、角色设定和制作流程与供应商 API 分离，避免更换模型时重写业务流程。
- 根据模型实际能力分配任务，例如整场音频创作、角色配音、音乐或音效生成；不假定所有模型拥有相同能力。
- 保留各模型特有的参数和能力限制，并记录生成版本使用的模型、参数及参考素材，便于比较和返修。
- 可采用单一模型完成场景，也可组合多个模型处理不同制作环节。具体首批接入模型在开发时确定。

具体接口、模型参数、存储和导出方案将在开发时确认。密钥与生成素材不提交到仓库。

## 名称

**Tale** 意为故事，**Weft** 意为纬线。TaleWeft 表达用声音编织故事的创作过程。
