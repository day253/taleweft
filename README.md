# TaleWeft · 织声

以故事为线，将人声、音乐与音效织成一部剧。

TaleWeft 面向有声剧、广播剧和有声书制作，计划通过 AI 音频创作模型，将剧本、角色表演、环境声与配乐组织成完整的声音作品。

## 项目状态

项目初始化阶段。当前仓库包含项目介绍，尚未实现业务功能或接通音频生成服务。

## 制作方向

- 剧本与分场：管理作品、分集、场景、对白和旁白。
- 角色与声音：记录角色设定、音色参考和表演指令。
- 音频创作：将对白、情绪、环境声和配乐编排为场景提示词，调用音频创作模型。
- 试听与返修：比较生成版本，标记问题并重做指定场景。
- 成品整理：组织分集音频、字幕和制作素材，支持后续导出。

## 技术方向

- **工作流编排**：Mastra / TypeScript。
- **音频创作模型**：火山引擎 Seed Audio 1.0。
- **制作单元**：以场景为单位组织生成与返修，再组成完整分集。

具体接口、模型参数、存储和导出方案将在开发时确认。密钥与生成素材不提交到仓库。

## 名称

**Tale** 意为故事，**Weft** 意为纬线。TaleWeft 表达用声音编织故事的创作过程。
